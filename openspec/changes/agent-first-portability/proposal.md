# Agent-first portability

## Why
Adapters currently expose fixed messaging/migration/hosting recipes and Product repeats role/template contracts. Brownfield instruction shadowing and root-only Maven detection can prevent the shared agent workflow from being applied. Cross-session work also needs an inspectable recovery record.

## What changes
Scope work through relevant agents and approved SA decisions; retire four fixed recipes; retain general framework support. Add selective Analysis/Discovery canonical Product profiles and PM/template aliases, explicit preferred skills, shared document contract and progressive context. Add opt-in Claude import/native wrappers, host-native/Claude seeds, bounded Maven detection, checkpoint/history/resume and a local manually populated comparison helper. Simplify README with English/Vietnamese/Chinese/Spanish navigation.

## Authority
User requested a single combined implementation/MR and removal of adapter design coupling. No merge, release or npm publication is authorized by this change. Host/runtime still supplies actual delegation, access, quota and enforcement.
