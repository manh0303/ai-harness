# Adapter capabilities
## Why
Flat rules and tool hints cannot expose technology skills or a repeatable verification/evaluation contract.
## What changes
Introduce schema-2 declarative adapters, topic rules, namespaced skills, advisory checklists and eight
agent evaluation scenarios. Add evidence-based detection with explicit opt-in installation. Read installed
capabilities from pinned snapshots. Preserve shared Core procedures and existing conflict guarantees.
## Impact
0.3 requires custom source adapters to migrate metadata; existing schema-1 project locks upgrade safely.
No automated command execution, model API calls, publication or merge is introduced.
