# Product, Architecture and Delivery

## Why
Product already contains BA/PO document skills but MVP outcomes, architecture decisions and delivery
coordination lack explicit linked contracts. Users also need accurate host setup instructions.

## What Changes
Complete Product MVP/outcomes and skill quality/examples; add optional Architecture and Delivery
capabilities, proportional handoffs and living project context. Extend new-doc with explicit capability
selection. Add documented setup for Codex, Claude Code, Cursor, Copilot and Gemini CLI.

## Impact
Reuse schema-1 capabilities/config/locks, existing install/update and OpenSpec. No new engine,
dependency or execution provider. Product module 1.2.0; new modules 1.0.0; distribution stays release-PR owned.
Research methods from BMAD, PM-Skills, arc42 and MADR with provenance; no upstream code or templates vendored.
