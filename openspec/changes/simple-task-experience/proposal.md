# Simple task experience

## Why
Users must interpret setup output, workflow choices and delivery status despite existing task-first
instructions. UIUX names emphasize Figma and live-host compliance is unmeasured.

## Scope
One feature PR: optional readable CLI, read-only chat orientation, actionable local status, canonical
workflow depth/context/handoff, neutral UI output selection, docs and newcomer evaluation protocol.
Reuse existing configs/checkpoints; preserve JSON/CLI compatibility and Figma skill IDs. User authorized
implementation and a reviewable PR on 2026-10-16. No merge/publish authorization is inferred.

## Limitations
No model/runtime/provider or new dependency. Live-host trials require unavailable executables/access;
remain NOT_RUN. Website-specific GitHub Actions changes belong to notth-web and are not included.
