# Contextual UI design quality

## Why
User reports generic, over-decorated UI from real NOTTH use. Current main already provides tool-neutral
delivery (UIUX 1.1.0), but design-system instructions are generic and review remains Figma-oriented.
Improve contextual design decisions, discoverable external skill handoffs and actual preview review.

## Scope
UIUX 1.2.0: two original NOTTH skills, one canonical design-source outline, pinned optional upstream
integration guide, selective entry/implementation/review chain, docs, tests and unscored evaluation.
No upstream library vendoring, auto-installs, runtime, schema/distribution bump or automatic publish.
External integration is a host-executed contract, not a new connector implementation.

## Acceptance
See specs/ui-design/spec.md. Preserve old Figma IDs and project data; only selected UIUX installs get
new assets. Never claim measured improvement or upstream execution from structural checks alone.
