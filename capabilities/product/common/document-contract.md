# Shared Product document contract

## Templates
Use the skill's canonical installed template only when creating a missing draft. Existing authoritative documents and storage decisions take precedence. new-doc never overwrites. Read artifacts.json/integrations.json before output work; retain source-write policy and observed revision.

## Quality
Keep source evidence, FACT/INFERENCE/DECISION/UNKNOWN, approval status, stable IDs and requirements distinct. Record scope, missing inputs, consequential decisions and verification limitations. Inspect only affected sections and preserve unrelated edits. Draft/static inspection is not runtime proof or business approval.

## Handoff
Carry source/requirement IDs, revision, accepted/proposed status, canonical destinations, owner, actual verification, blockers and next action to the relevant BA/PO/SA/PM/Developer/QA. Reuse product-to-solution and continuous-development workflows. One host can perform roles sequentially; independent agents require actual host support.
