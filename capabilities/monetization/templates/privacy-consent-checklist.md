# Publisher privacy and consent checklist

Version: 0.1-draft | Status: pending-review | Owner: <site owner/compliance reviewer>
Policy review date: <date> | Regions served: <unknown until checked>

## Content and site ownership
- [ ] Publisher owns or is authorized to monetize website/content
- [ ] Ad network eligibility and live approval status verified (not assumed)
- [ ] Original useful content/tools and accessible navigation
- [ ] No deceptive ad labels, click inducement, invalid traffic or restricted-content bypass

## Consent and privacy
- [ ] Actual data collection and cookies/tracking disclosed
- [ ] Applicable privacy policy and user rights reviewed for served regions
- [ ] EEA/UK/Switzerland: review Google-certified CMP + IAB TCF rules where applicable
- [ ] Consent choices and revocation tested; no personalized ads served before required consent
- [ ] Third-party tags and analytics load only in permitted modes
- [ ] Browser tools do not upload sensitive files without a justified user-facing explanation
- [ ] CMP provider choice and integration evidence, if required

## Implementation and policy verification
- [ ] Exact network terms, publisher account and site approval source checked
- [ ] ads.txt checked at root URL with **real account-provided** seller entry (recommended by Google)
- [ ] Ads not confused with Download/Generate buttons, menus or image previews
- [ ] Mobile responsiveness and keyboard interaction reviewed
- [ ] Ad-block/no fill/no-consent fallback preserves tool functionality
