## Fit and limits
Harness keeps OpenSpec as the change record and a single manifest-driven instruction distribution.
Core applies a compact overview/impact check; capabilities add depth when selected. Product Manager
owns product value; Project Manager owns delivery coordination; role names do not make approvals.
No workflow engine, upstream prompt bundle, provider credentials or public account data was copied.

Research proves source/format availability, not Harness model effectiveness. Behavioral cases remain
unscored until real host runs and reviewed traces exist. Native host configuration references below
were checked against official docs; installed-client behavior still requires the smoke procedure in
[tool setup](../tool-setup/README.md). Recheck sources before changing host discovery recommendations.
